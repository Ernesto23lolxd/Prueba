# STOCK en el celular

STOCK se instala desde el navegador como app (PWA) o con el APK de Android. Abre en pantalla completa y usa micrófono,
cámara y archivos.

Enlace: https://stock-tienda.onrender.com/app

## APK de Android
Descarga: https://github.com/Ernesto23lolxd/Prueba/releases/download/apk/STOCK.apk

1. Descargar `STOCK.apk` en el celular.
2. Abrirlo y permitir "Instalar apps de esta fuente".

Es una Trusted Web Activity (paquete `mx.stock.tienda`, Android 5.0 o más) y necesita Chrome. Lo compila GitHub
Actions. Está firmado con una llave de demostración; para Play Store hace falta una llave privada.

## Instalar como PWA
- Android: menú de STOCK, Instalar en mi celular.
- iPhone: en Safari, Compartir, Agregar a pantalla de inicio.
- Computadora: ícono de instalar en la barra de direcciones de Chrome o Edge.

## Ajustes para celular
Respeta muescas y barras de gestos, no hace zoom al escribir en iPhone, abre sin señal con la última copia guardada y
se probó de 320 px a tabletas. Los datos siempre vienen del servidor.
